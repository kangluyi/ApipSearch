# 核心功能

## IP 自动识别

插件会自动检测访客的 IP 地址类型（IPv4 / IPv6），无需手动区分，同一套接口处理双栈请求。

## 多数据源支持

| 数据源 | IPv4 | IPv6 | 说明 |
|--------|------|------|------|
| 百度地图 | ✅ | ✅ | 默认数据源，覆盖面广 |
| 高德地图 | ✅ | ✅ | 精度高，适合国内场景 |
| 自定义源 | ✅ | ✅ | 支持对接自有 IP 定位服务 |

## 定位结果展示

- **地理位置**：国家、省份、城市
- **运营商信息**：ISP 运营商识别
- **IP 类型**：区分 IPv4 / IPv6

## 插件化平台接入

支持多种平台接入方式：

- **CMS 插件**：迅睿 CMS 等主流建站系统
- **独立站**：通过 API 接口直接调用
- **机器人**：集成到 Bot 场景中做来源判断

## 隐私友好

只采集查询所需的最小字段，不记录多余的用户信息，适合对隐私有要求的站点。
