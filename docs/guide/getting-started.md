# 快速开始

## 环境要求

- PHP 7.4+（推荐 PHP 8.0+）
- MySQL 5.7+
- 支持 IPv4 / IPv6 的服务器环境

## 安装步骤

### 1. 获取插件

从 [GitHub Releases](https://github.com/MoruTeaven/ApipSearch-docs/releases) 下载最新版本的插件包。

### 2. 上传安装

将插件包上传到你的站点 `/plugins/` 目录下并解压。

### 3. 启用插件

进入后台管理 → 插件管理 → 找到 **ApipSearch** → 点击启用。

### 4. 配置数据源

启用后在插件设置页中选择数据源（百度 / 高德），并填入对应的 API Key。

## 验证安装

安装完成后，访问任意页面，插件会自动识别访客 IP 并进行定位。你可以在后台日志中查看查询记录。

::: tip
如果遇到 IPv6 无法定位的问题，请确认你的服务器支持 IPv6 双栈，并且所选数据源支持 IPv6 查询。
:::
